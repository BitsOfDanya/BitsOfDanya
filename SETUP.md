# Installation

Upload these files to the root of `BitsOfDanya/BitsOfDanya`:

```text
README.md
.github/
└── workflows/
    └── snake.yml
```

Then:

1. Commit the files to the default branch.
2. Open the repository **Actions** tab.
3. Open **Generate contribution snake**.
4. Click **Run workflow** once.
5. Wait for the `output` branch to be created.
6. Reload `https://github.com/BitsOfDanya`.

The snake then refreshes automatically once per day.

The README deliberately does not use `github-readme-stats` or
`github-profile-summary-cards` so a third-party stats outage does not
leave broken image placeholders in the middle of the profile.
