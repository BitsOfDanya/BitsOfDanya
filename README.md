## `01 / ABOUT`

I'm **Daniil Chepko** — a Machine Learning Engineer, software builder and tech lead.

I work at the intersection of **machine learning, backend engineering and product development** — from experiments and ML pipelines to system architecture, APIs, interfaces and production infrastructure.

I like building products from zero: turning an idea into a technical architecture and then into a system people can actually use.

```text
Research  →  Architecture  →  Engineering  →  Production
```

My main areas of interest are **Computer Vision, NLP, embeddings, multimodal ML, backend systems and AI-powered products**.

## `05 / ENGINEERING`

I don't limit myself to the model layer.

A product usually requires much more:

```text
                     PRODUCT

        ┌──────────────┼──────────────┐
        │              │              │
        ▼              ▼              ▼
   MACHINE          BACKEND        FRONTEND
   LEARNING         SYSTEMS        PRODUCT UI
        │              │              │
        └──────────────┼──────────────┘
                       ▼
                 INFRASTRUCTURE
                       │
                       ▼
                  PRODUCTION
```

That is the area I enjoy working in most — **connecting ML, software architecture and product engineering into one system**.
